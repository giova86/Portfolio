Overview

Dead Space is a text-driven investigation game for Android and iOS. The player is special agent Kara Voss, called to an underground military base after a colonel is found dead — apparent cardiac arrest, but the first examination points elsewhere. There are 24 real hours to unmask the killer.

The interface is built around a detective's toolkit rather than a generic next button: an action bar lets the player investigate one of six areas, interrogate a suspect or make the final accusation, and an evidence notebook lists every clue found.

Story, artwork and music change with every scene, with text typed out on screen and soundtracks that fade smoothly from one track to the next.

What it does

The case

  • Branching story with six searchable areas and eight suspects
  • Choices that stay locked until the player holds the matching clue
  • A final accusation with a written outcome for each suspect — only one is guilty

Time pressure

  • 24-hour countdown that keeps running even while the app is closed
  • Running out of time leads to a mission-failed screen
  • Investigation can be resumed or restarted from the home screen

Evidence

  • Notebook of clues grouped by where they were found
  • Badge for unread evidence and a collected counter

Atmosphere

  • Typewriter narration and cross-fading scenes
  • Adaptive soundtrack with smooth crossfades
  • Built-in briefing explaining the rules

How it is built

Behind the narrative sits a small data-driven story engine: the whole case lives in a single data file, so the story can be rewritten or replaced without changing the code. The app is built with Flutter and Dart, persists progress locally and falls back gracefully when an image or audio file is missing.

Tech stack

Dart

Implements the story engine: the StoryNode / Option model, JSON parsing, the clue set and unlock checks, the accusation logic and the GameTimer that computes remaining time from a persisted start timestamp.

Flutter

Renders the whole experience — home screen, scene view with its typewriter text and fading background, area and suspect pickers, notebook, accusation panel and timeout screen — from one codebase on Android and iOS, using explicit animation controllers for every transition.

audioplayers

Plays the per-scene soundtrack on loop and provides the volume control used to crossfade between tracks when the narrative moves to a node with different music.

shared_preferences

Persists the game start time and the set of discovered clues, making the 24-hour countdown real (it elapses whether or not the app is open) and letting the player resume an investigation later.

collection

Provides the grouping and lookup helpers used to organise collected clues by their source area in the notebook view.

JSON story format

A declarative node format (id, text, image, music, options, cluesObtained) that keeps the case entirely in data — new scenes, suspects or whole cases are authored, not coded.
