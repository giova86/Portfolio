Overview

YTDown is a self-hosted web app for downloading YouTube content from the browser — a single video or an entire playlist, as MP3 audio at 192 kbps or MP4 video at the best available quality. It is deliberately a local tool rather than a service: no ads, no limits and no third party in the middle.

The flow is built around inspecting before downloading. Paste a link and the app shows the title, thumbnail, duration and, for a playlist, the full track list, so you can confirm the target before anything is saved.

Playlists are packaged into a single archive, so a forty-track download is still one file to save, and a live progress bar follows the actual transfer.

What it does

Download

  • Single video or full playlist
  • Audio or video
  • Playlist delivered as one ZIP

Preview and progress

  • Title, thumbnail and duration shown before the download
  • Real-time progress, not a placeholder spinner
  • The page stays responsive while the download runs

Private and simple

  • Everything runs locally with no account
  • Dark interface split into clear components
  • Interactive documentation for the underlying API

How it is built

A compact FastAPI back end wraps yt-dlp, with ffmpeg handling audio extraction and conversion, and publishes interactive API documentation so it can be used independently of the interface. The React front end is built with Vite and talks to it through a proxy, with downloads running as background tasks.

Tech stack

Python

Implements the backend: URL resolution, the background download tasks, the per-task progress state and the ZIP bundling of playlist downloads.

FastAPI

Exposes the four endpoints (info, start, progress stream, file retrieval), handles the SSE response and auto-generates the Swagger documentation at /docs.

yt-dlp

The download engine — metadata extraction for the preview, the actual media transfer, and the progress callback that drives the SSE stream.

Server-Sent Events

Streams per-task progress from server to browser over a plain HTTP connection, avoiding the polling loop a REST-only design would need.

React

Builds the UI from four components — URL input, video preview, playlist track list and download panel — holding the task state that the SSE stream updates.

Vite

Development server and bundler for the front end.

ffmpeg

Performs the audio extraction and the MP3 encoding at 192 kbps, and the muxing for video downloads.

Uvicorn

The server running the FastAPI app.
