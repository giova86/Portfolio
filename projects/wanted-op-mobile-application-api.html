Overview

Wanted OP is the mobile counterpart to the One Piece wanted-poster generator, built with Flutter to run natively on both iPhone and Android.

Upload a photo from the gallery or take one with the camera, enter a name, set a custom bounty, and the app returns your own wanted poster. The poster is generated by a FastAPI service written in Python.

The interface is inspired by the One Piece wanted-poster aesthetic.

What it does

Create

  • Photo from the gallery or the camera
  • Custom name and bounty amount
  • Real-time preview of the generated poster

Keep

  • Save the finished poster as an image on the device
  • Interface that follows the look of the original posters

How it is built

The client is a Flutter and Dart app that sends the photo and the poster details to a FastAPI backend, which composes the poster and returns it to the phone.

Tech stack

Python

Backend language for the poster-generation service consumed by the app.

FastAPI

Exposes the API that composes the uploaded photo, name, and bounty into the final poster image.

Dart

Application logic: state management and coordinating image picking, preview, and saving.

Flutter

Cross-platform UI for iPhone and Android, including the image picker, live poster preview, and screenshot/save flow.
