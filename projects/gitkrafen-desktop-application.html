GitKrafen - Desktop Application

A desktop Git client modelled on GitKraken: lane-based commit graph, staging, conflict editor, integrated terminal and AI commit messages.

Electron React TypeScript Git

Overview

GitKrafen is a full-featured desktop Git client built with Electron, React and TypeScript, modelled on GitKraken 12.x: the same tabbed layout, toolbar, side panel, lane-based commit graph with avatars, and WIP / commit panel on the right, with the same day-to-day workflow. It is a personal project born from a simple question — how much of a commercial Git GUI can be rebuilt on top of the plain git command line?

The back end deliberately does not reimplement Git: every operation shells out to the system git, so each action behaves exactly as it would in a terminal — same hooks, same config, same results. On top of that thin layer the app adds what a GUI is good at: a virtualised graph that stays smooth with 20,000 commits and 25 parallel branches, hunk- and line-level staging, a three-way merge editor, drag-and-drop between branch pills, and real-time updates driven by a filesystem watcher (about half a second, even for changes made outside the app).

It also goes beyond the original in a few places: a permanent Launchpad home listing every repository with live status, a colour legend with high-contrast, stable branch colours (ΔE ≥ 40 between any pair), privacy-friendly avatars, and optional AI commit messages with the engine of the user's choice. A one-command script builds a signed macOS DMG, and the whole project is covered by a Vitest suite that runs against real temporary repositories.

Key features

  • Lane-based commit graph — coloured lanes, avatars (Gravatar, initials only, or none), merged local+remote branch pills, tags, stashes, a dashed // WIP row and day separators; click a branch to highlight all of its commits and dim the rest.
  • Virtualised and live — paged loading and row virtualisation, tested with 20,000 commits; a filesystem watcher refreshes the view within ~0.5 s of any change.
  • Fine-grained staging — stage, unstage or discard whole files, hunks or single lines; inline and side-by-side diffs with syntax highlighting, blame, file history and direct editing.
  • Full history tooling — merge (--no-ff, squash), rebase, interactive rebase (pick / reword / squash / fixup / drop), cherry-pick, revert, reset, range squash, reword of non-HEAD commits, Undo/Redo, and drag & drop between branch pills.
  • Three-pane conflict editor — Ours · Base · Theirs, with the base taken from the common ancestor via git merge-file --diff3, per-block resolution, editable output and handling of modify/delete and binary conflicts.
  • Hosting integrations — GitHub, GitHub Enterprise, GitLab, Bitbucket and Azure DevOps with OAuth/SSO (Device Flow, PKCE) or tokens encrypted in the system keychain: private clones, pull requests, issues and a Launchpad of PRs and WIPs.
  • Launchpad home — a permanent list of all repositories with live branch, changes, ahead/behind and last-commit status, plus search, filters, favourites and grid or list view.
  • Integrated terminal — a real pty (node-pty + xterm.js) with login shell, colours, less/vim and synchronised resizing.
  • Optional AI — “Generate with AI” fills the commit title and description from the staged diff, using OpenAI, Claude, Gemini, Mistral, Groq, DeepSeek, OpenRouter, Ollama, LM Studio or any OpenAI-compatible endpoint; keys stay in the keychain.
  • Extras — command palette (⌘P), dark/light theme, submodules, worktrees, Git Flow, Git LFS patterns, GPG/SSH-signed commits, author statistics.
  • Tested and packaged — unit and integration tests with Vitest on real temporary repositories, and a build script that assembles, ad-hoc signs and verifies a macOS DMG.

Tech stack

Electron

Desktop shell: window and menus, IPC, the system git service, encrypted secrets in the keychain, OAuth loopback flows and the pty bridge for the integrated terminal.

React

The whole interface — virtualised commit graph, diff and merge views, Launchpad, dialogs and command palette — built with React 18 and bundled with Vite.

TypeScript

Strictly typed renderer, including pure, well-tested modules for graph layout, diff/patch building and conflict parsing.

Git

Every repository operation runs through the system git, so behaviour, hooks and configuration are identical to the command line.
