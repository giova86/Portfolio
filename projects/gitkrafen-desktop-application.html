GitKrafen - Desktop Application

A desktop Git client modelled on GitKraken: lane-based commit graph, staging, conflict editor, integrated terminal and AI commit messages.

Overview

GitKrafen is a full-featured desktop Git client modelled on GitKraken: the same tabbed layout, toolbar, side panel, lane-based commit graph with avatars and a commit panel on the right, with the same day-to-day workflow.

It started from a simple question: how much of a commercial Git GUI can be rebuilt on top of the plain git command line? Every operation runs through the system git, so each action behaves exactly as it would in a terminal — same hooks, same configuration, same results — while the app adds what a GUI is good at.

It also goes beyond the original in a few places: a permanent Launchpad home listing every repository with live status, stable high-contrast branch colours, privacy-friendly avatars and optional AI-written commit messages.

A graph that stays smooth

The commit graph draws coloured lanes with avatars, merged local and remote branch labels, tags, stashes and day separators. Click a branch to highlight all of its commits and dim the rest.

It is virtualised, so it stays fluid with tens of thousands of commits and many parallel branches, and a file-system watcher refreshes the view within about half a second of any change, even if it was made from another tool.

What it does

Everyday workflow

  • Stage, unstage or discard whole files, hunks or single lines
  • Inline and side-by-side diffs with syntax highlighting, blame and file history
  • Drag and drop between branch labels to merge or rebase

Full history tooling

  • Merge, squash, rebase and interactive rebase
  • Cherry-pick, revert, reset and reword of older commits
  • Undo and redo for repository operations

Conflict resolution

  • Three-pane editor showing ours, base and theirs
  • Per-block resolution with an editable result
  • Handles modify/delete and binary conflicts

Connected to your hosting

  • GitHub, GitHub Enterprise, GitLab, Bitbucket and Azure DevOps
  • Sign-in with OAuth/SSO or tokens kept in the system keychain
  • Pull requests, issues and private clones

Launchpad home

  • Every repository with live branch, change and ahead/behind status
  • Search, filters, favourites and grid or list view

Extras

  • Integrated terminal with a real shell
  • Optional AI commit messages from the staged changes, with keys kept in the keychain
  • Command palette, dark and light theme, submodules, worktrees, Git Flow, LFS and signed commits

How it is built

The application is an Electron app with a React and TypeScript interface. A thin back end launches the system git for every operation and parses its output, rather than reimplementing Git, which keeps behaviour identical to the command line.

The project is covered by an automated test suite that runs against real temporary repositories, and is packaged as a signed macOS DMG by a single script.

Tech stack

Electron

Desktop shell: window and menus, IPC, the system git service, encrypted secrets in the keychain, OAuth loopback flows and the pty bridge for the integrated terminal.

React

The whole interface — virtualised commit graph, diff and merge views, Launchpad, dialogs and command palette — built with React 18 and bundled with Vite.

TypeScript

Strictly typed renderer, including pure, well-tested modules for graph layout, diff/patch building and conflict parsing.

Git

Every repository operation runs through the system git, so behaviour, hooks and configuration are identical to the command line.
