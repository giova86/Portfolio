Face Tracking

A Python computer-vision tool that turns any webcam into an intelligent, auto-framing virtual camera. Built on MediaPipe's FaceMesh, it tracks the speaker's face in real time, smoothly recentres and zooms the frame, and streams the result to any app that accepts a virtual camera — no extra hardware needed.

Overview

Face Tracking turns a static webcam feed into an auto-framing virtual camera for video calls, online classes and streaming. Rather than a fixed frame, it continuously detects the speaker's face and recentres and crops the video so the subject stays framed as they move — with no extra hardware.

The face position is smoothed in two stages, first with a weighted moving average that favours recent frames and then with an exponential filter, so the camera glides instead of jerking. If the face briefly leaves the frame, its movement is extrapolated so the crop keeps moving fluidly instead of snapping back to the centre.

The result is streamed to a virtual camera, so OBS, Zoom, Google Meet, Discord or Teams can use it as a regular webcam.

A camera operator in software

Zoom and the active area are configurable, removing empty space for a more professional look. A multi-face variant switches automatically between a unified frame for two people and a synchronised split-screen as the speakers move apart.

What it does

Tracking

  • Face tracked through a stable landmark on the nose bridge
  • Motion prediction when the face is momentarily lost
  • Automatic choice of the best detection configuration at startup

Framing

  • Dynamic zoom on a configurable active area
  • Two-stage smoothing for fluid motion
  • Unified or split-screen view for two people

Everywhere

  • Works with any app that accepts a webcam
  • Headless mode for servers and background use
  • Configurable zoom, smoothing, resolution, frame rate and camera

How it is built

A MediaPipe face-mesh model runs on every frame captured through OpenCV, and the cropped result is published through a virtual-camera backend.

Tech stack

Python

Core language for the whole pipeline; an argparse-driven CLI exposes zoom, smoothing, resolution, FPS, and camera-device settings so the tool can be tuned per use case without touching code.

OpenCV

Captures frames from the physical webcam, handles colour-space conversion, crops and resizes the tracked region with cubic interpolation, and draws the debug overlays shown in the preview windows.

Mediapipe

Runs the FaceMesh model that detects facial landmarks on every frame; the app uses the nose-bridge point as a stable tracking anchor and falls back through progressively looser detection/tracking confidence configs if the strictest one fails to load.

PyVirtualCam

Streams the cropped, recentred frame to a system-level virtual camera device, so any conferencing or streaming app can pick it up as a normal webcam source.
