Playlist Downloader

Web app to download playlists from YouTube or Spotify quickly, easily, and with the best format and quality options.

Python Streamlit
2sources: Spotify and YouTube
192 kbpsMP3 output
Multicoreparallel downloads for long playlists
ID3tags and album art embedded

Overview

Playlist Downloader is a web app that turns whole playlists from Spotify or YouTube into tagged MP3 files. The interface is two tabs and one field: paste a playlist link, press Download and watch the progress track by track.

Spotify does not serve audio, so for Spotify playlists the app reads titles, artists and album art from Spotify and finds the matching audio on YouTube, retrying when a search fails so one bad lookup never stops the whole playlist. YouTube playlists are expanded and downloaded directly.

Every file ends up in a folder named after the playlist with correct tags and embedded cover art.

What it does

Two sources, one interface

  • Spotify and YouTube playlists in separate tabs
  • Share links accepted as they are
  • Malformed or non-playlist links reported as friendly warnings

Quality

  • Right titles, artists and covers from Spotify even when the video title differs
  • Embedded album artwork
  • 192 kbps MP3 conversion

Speed and feedback

  • Long Spotify playlists split across several processor cores, with some cores kept free
  • Live per-track progress
  • Button to open the download folder

Setup

  • Credentials kept in a separate local file outside the code
  • Custom styling instead of the default look

How it is built

The app is built with Streamlit. Audio is downloaded and converted with yt-dlp and ffmpeg, Spotify metadata comes from its web API, and tags are written with mutagen. A multiprocess handler distributes the work and streams progress to the page.

Tech stack

Python

Orchestrates the whole pipeline: playlist expansion, the reference-file format, the search/download /tag loop, the multicore segmentation and the OS-specific folder opener.

Streamlit

Provides the two-tab UI, the URL inputs, the buttons and the live status placeholders, plus the injected CSS that restyles the page.

spotipy

Authenticates with client credentials against the Spotify Web API and walks the playlist to collect each track's title, artist, album and cover-art URL.

yt-dlp

Downloads the audio for both paths — the matched YouTube video for a Spotify track, or the playlist entries directly — and runs the ffmpeg post-processors.

youtube-search

Resolves each Spotify track to a YouTube URL by querying "artist – title" and taking the best result, with a retry budget per track.

mutagen

Writes the ID3 tags on the finished MP3 and embeds the Spotify album artwork as an APIC frame.

ffmpeg

Extracts and encodes the audio to 192 kbps MP3 and writes the container metadata, invoked through yt-dlp's post-processor chain.

multiprocessing

Splits long playlists into per-core segments so several tracks download in parallel, with a configurable core budget.
