ConvertToMD - Web Application

A fully local web application that converts PDF, DOCX, DOC, XLSX, and XLS files into Markdown.

5document formats
100%local — no file leaves your machine

Page by pagereview and re-run

Overview

ConvertToMD converts PDF, Word and Excel files into clean, well-structured Markdown, entirely on your own machine — no document is ever uploaded to an external service.

It offers two conversion paths depending on the format: Word and Excel files are read structurally, keeping headings, emphasis and tables, while PDFs and scans are converted page by page with a locally hosted vision-language model acting as OCR.

The interface is a split-view editor: the original page on one side, its Markdown on the other, so every page can be checked and re-run before the file is downloaded.

Inspect every page

Toggle between a rendered preview and the raw Markdown while the text is produced. Convert a single page, or queue the whole document: pages already done are skipped, so a long run can resume after an interruption.

If a page comes out garbled, re-run just that page with a different model, without restarting the document.

What it does

Conversion

  • Structure-preserving extraction for Word documents and Excel workbooks
  • OCR for PDFs with a local model, page by page or all at once
  • Result downloaded as a single Markdown file

Local models

  • Choose between Ollama, LM Studio and vLLM from a settings panel
  • A connection test lists the models actually available
  • Per-page model override

Everyday comfort

  • Dark mode across the whole interface
  • No API key required
  • A command-line batch converter for whole folders

How it is built

A React front end talks to a FastAPI back end written in Python. The OCR layer sits behind a small abstraction so that any compatible local model server can be plugged in, and Word and Excel conversion is deterministic and never touches the model.

Tech stack

Python

Backend language for the FastAPI service, the DOCX/XLSX converters, and the standalone CLI batch script.

FastAPI

Exposes the REST API — upload, direct conversion, PDF bridging, per-page OCR, and settings/model endpoints — consumed by the React front end.

React

Drives the whole interface: the upload zone, the mode-selection step, the split-view editor with its page strip and model picker, and the settings modal — built with Vite and Tailwind CSS.

HTML

Markup foundation for the app shell and the Vite-built static output served to the browser.

Ollama

Default local model server for the OCR path — runs the vision-language model that turns a rendered page image into Markdown, with no data leaving the machine.

LLM

A vision-language model (glm-ocr by default) reads each rendered page image and returns structured Markdown — headings, tables, lists — through a backend-agnostic interface that also supports LM Studio and vLLM.
