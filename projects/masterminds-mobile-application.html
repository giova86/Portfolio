Masterminds - Mobile Application

Mobile version of the famous boardgame Mastermind created by Mordecai Meirowitz in 1970.

Dart Flutter

Overview

Masterminds is a mobile implementation of Mastermind, the code-breaking board game designed by Mordecai Meirowitz in 1970. The device plays codemaker: it generates a secret sequence of four coloured pegs from a palette of eight, with repetitions allowed, and the player has ten attempts to break it.

Input is built for touch rather than ported from a physical board: each of the four pegs in the active row cycles through the palette when tapped, so an entire guess is composed with a few thumb taps in one place.

After each submission the board shows the classic feedback: a black marker for every peg that is right in colour and position, a white marker for the right colour in the wrong position, and grey placeholders for the rest.

What it does

Rules

  • Random secret code with repeated colours allowed
  • Duplicate-aware scoring so repeated colours are never counted twice
  • Inline warning if a row is incomplete, without losing an attempt

Learning to play

  • Built-in tutorial covering the goal, the entry of a guess and the feedback markers
  • Suggested opening strategy
  • Full guess history on the board

Presentation

  • Animated home screen with Play and Instructions
  • Pulsing highlight on the active row
  • Dark slate theme with custom artwork; board scales to any phone size

How it is built

A Flutter app with no external dependencies, written in Dart for Android and iOS. Result dialogs reveal the secret code at the end of a game and let the player start a new round at any moment.

Tech stack

Dart

Implements the entire game: random secret-code generation, the peg-cycling input model, the two-pass black/white feedback algorithm, win/lose detection and the round lifecycle.

Flutter

Builds the cross-platform UI for Android and iOS — the animated home screen, the ten-row game board with its colour palette and feedback columns, the instructions screen and the end-of-game dialogs — with state handled through StatefulWidget and setState.

Flutter animation framework

AnimationControllers driven by TickerProviderStateMixin power the home screen entrance animation and the repeating pulse that marks which row is currently in play.

No external dependencies

Beyond cupertino_icons, the app pulls in no third-party packages: the game logic, the rendering and the state management are all first-party code, which keeps the build reproducible and the binary small.
