BeeKeeper Plus - Desktop Application

A desktop SQL editor for nine database engines, with a CodeMirror query editor, a charting panel, inline data editing, report export and an AI assistant.

Overview

BeeKeeper Plus is a desktop SQL editor and database browser modelled on the look and feel of Beekeeper Studio: one dark window with a connection manager, a tree of tables and views, tabbed query editors and a results grid.

It talks to SQLite, libSQL/Turso, DuckDB, PostgreSQL, MySQL, SQL Server, ClickHouse, MongoDB and Redis through the same interface, so switching from a local file to a production server does not change the way you work. Results can be sorted, inspected in a JSON sidebar, edited in place, exported or turned into charts.

On top of the editor it adds a report builder that collects queries, data excerpts, charts and notes into a shareable bundle, and an AI assistant that turns questions in plain language into queries for the connected schema.

A personal project

Built to see how far a commercial-grade database client can be recreated with web technologies in a desktop shell.

From query to chart

Write a query in an editor with syntax highlighting and schema-aware autocomplete, run it at the cursor or all at once, and read the answer in a sortable grid with a JSON view of the selected row.

Switch the same result to a chart: columns map to axes, colour and size, with bars, lines, areas, scatter plots, histograms, box plots, pies and heatmaps, and the picture can be exported as an image.

What it does

Many engines, one UI

  • Nine engines, each with a dedicated driver
  • Saved connections stored locally, passwords encrypted with the system keychain
  • Table browser with paged data, filters and a structure view of columns, indexes and foreign keys

Query editor

  • Multiple tabs, run-at-cursor or run-all
  • Query history and saved queries per connection, with import and export
  • Changes to columns and indexes are reviewed as SQL before they are applied

Results and data

  • Sortable grid with cell selection and a JSON sidebar
  • Inline editing of table data
  • Import CSV files into tables; export results as CSV, JSON or SQL

Charts

  • Eight chart types with stacked or grouped bars and log scale
  • Up to 50,000 rows drawn smoothly
  • PNG and SVG export

Reports

  • Add queries, result excerpts, charts and text blocks to a draft per connection
  • Preview as Markdown and export everything as a ZIP with the chart images

AI assistant

  • Natural-language questions answered with SQL, Mongo or Redis commands for your schema
  • Works with cloud providers or local models such as LM Studio and Ollama, or any compatible endpoint

How it is built

Each database engine has its own driver running in the application's main process behind a shared messaging layer, so the interface only ever deals with queries, result sets and table structures. The interface is a Vue 3 application with a CodeMirror 6 editor, and charts are drawn with Plotly.

The app is packaged as a signed macOS bundle and DMG, and is verified by unit tests and an end-to-end suite that drives the real application.

Tech stack

Electron

Desktop shell: main process, IPC and preload bridge, the per-engine database drivers, the AI providers and encrypted credential storage through safeStorage.

Vue

The whole interface — workspace tabs, entity tree, results grid, chart panel, structure editor and report builder — written with Vue 3 single-file components and bundled with Vite.

Javascript

Plain JavaScript on both sides of the IPC boundary, including pure, unit-tested modules for statement splitting, autocompletion, chart data and report generation.

SQL

CodeMirror 6 SQL editing with dialect-aware completion, plus drivers for relational, analytical and embedded engines (better-sqlite3, pg, mysql2, mssql, DuckDB, ClickHouse and libSQL).
