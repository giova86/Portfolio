Face Recognition

Real time face recognition. Identify people in real time providing extra information.

Python dlib OpenCV NumPy

Overview

Face Recognition is a real-time identification system built on a live camera feed. It detects every face in frame, matches it against a local database of known people, and overlays a cyberpunk-style HUD showing who each person is, how confident the match is, their avatar, and whatever extra information has been recorded about them — birthday and social handles.

The recognition core is face_recognition (dlib): each known image is converted into a 128-dimensional face encoding, and every frame's detected faces are encoded and matched against that database by nearest distance, which is then turned into a percentage confidence. Detection runs on a downscaled copy of the frame — 25 % by default, tunable — while the HUD is drawn at full resolution, so the app stays interactive without giving up output quality.

What makes it practical rather than a demo is that the database manages itself. Adding a person is just dropping images into known_people/ named Name.jpg, Name_1.jpg, Name_2.jpg — the name is parsed from the filename and multiple images of the same person are merged to improve accuracy. On launch the app hashes the folder, and if anything was added or removed it rebuilds the encodings into model.csv / names.csv, crops a new avatar for each new person into known_avatar/, and deletes avatars for people who are gone. If nothing changed, the cached model is reused and startup is instant; -f forces a rebuild anyway.

The HUD is the visible half of the project. Each face gets neon targeting brackets — cyan for a known person, red for an unknown one — a floating label chip with name and match confidence, the person's avatar drawn beside the face and joined to it by a glowing magenta link, and a translucent data panel listing name, confidence, birthday and social handles read from info.csv. A status bar along the bottom carries a blinking scan indicator, the live face count and the current FPS. The whole look is driven by a single THEME dictionary, so colours and geometry are re-skinnable without touching the recognition code. A companion Instaloader scraper can bootstrap the known-people folder from an Instagram follower list.

Key features

  • Real-time recognition — faces are detected, encoded and matched against the local database on every frame from any connected camera, with a live FPS readout.
  • Confidence scoring — the nearest-neighbour distance from the 128-d encoding is converted into a match percentage shown next to each name, so borderline identifications are visible rather than silently asserted.
  • Self-managing database — the app hashes known_people/ on launch and rebuilds avatars and encodings only when images were added or removed; otherwise the cached model in model.csv / names.csv is reused for an instant start.
  • Multi-image enrolment — several photos of the same person (Name_1.jpg, Name_2.jpg, …) are collapsed onto one identity, improving robustness to pose and lighting; names are derived from the filenames, with no manual labelling step.
  • Automatic avatar generation — the first image of each person is cropped around the detected face into an avatar, a default Unknown.jpg is generated for unrecognised faces, and stale avatars are cleaned up.
  • Cyberpunk HUD overlay — neon targeting brackets (cyan known / red unknown), a floating name-and-confidence chip, the avatar tethered to the face by a glowing link, a translucent data panel and a bottom status bar with a blinking scan indicator and face count.
  • Extra person data — an optional info.csv (name, birthday, Facebook, Instagram) is joined to each recognised face and rendered in the data panel; a template is created on first run.
  • Performance/accuracy trade-off exposed — --rescale controls the detection downscale factor (0.25 by default) so the same code runs on a laptop webcam or a high-resolution feed.
  • Full CLI — camera id, known-people folder, rescale factor, avatar size and forced model rebuild are all command-line flags.
  • Re-skinnable theme — every colour and HUD dimension lives in a single THEME dictionary at the top of app.py.
  • Instagram bootstrap scraper — an Instaloader-based helper can pull profile pictures from a follower list to populate the known-people folder.

Tech stack

Python

The whole application in a single ~750-line app.py: database hashing, avatar management, model caching, the frame loop and every HUD drawing helper.

face_recognition (dlib)

Provides face detection and the 128-dimensional encodings used for identification, along with the distance metric that becomes the displayed confidence score.

OpenCV

Captures the camera stream, downscales frames for detection and draws the entire HUD — brackets, avatars, connector lines, translucent panels and text — onto the full-resolution frame.

NumPy

Handles the encoding arrays and the distance computation between the live face and every entry in the cached model.

pandas

Reads and writes the CSV-backed store — model.csv, names.csv and the optional info.csv with each person's birthday and social handles.

Pillow

Crops and resizes the avatar images generated from the known-people photographs.

Instaloader

Powers the optional scraper that collects profile pictures from an Instagram follower list to seed the known-people database.
