Overview

Face Recognition is a real-time identification system built on a live camera feed. It detects every face in frame, matches it against a local database of known people, and overlays a cyberpunk-style HUD showing who each person is, how confident the match is, their avatar and extra information.

Each known photo is turned into a numeric face encoding, and every face in the live frame is matched to the closest one, with the distance converted into a percentage confidence — so borderline identifications are visible rather than silently asserted.

The database manages itself: adding a person just means dropping photos into a folder named after them, and several photos of the same person are merged to improve robustness to pose and lighting.

What it does

Recognition

  • Detection and matching on every frame from any connected camera
  • Confidence shown next to each name
  • Adjustable speed and accuracy trade-off to suit a laptop webcam or a high-resolution feed

Self-managing database

  • Avatars and encodings rebuilt only when photos change
  • Instant start from a cached model
  • Several photos per person merged into one identity

HUD overlay

  • Neon targeting brackets: cyan for known people, red for unknown
  • Name and confidence chip, with the person's avatar tethered to the face
  • Data panel with optional birthday and social profiles, plus a status bar with the face count

Customisable

  • Every colour and HUD dimension in one theme
  • Command-line options for camera, folder and sizes

How it is built

The recognition core relies on dlib's face encodings, with OpenCV handling the camera and the drawing of the overlay. Detection works on a downscaled frame to keep the frame rate high, and the whole project is plain Python with a small set of data files.

Tech stack

Python

The whole application in one script: database hashing, avatar management, model caching, the frame loop and every HUD drawing helper.

face_recognition (dlib)

Provides face detection and the 128-dimensional encodings used for identification, along with the distance metric that becomes the displayed confidence score.

OpenCV

Captures the camera stream, downscales frames for detection and draws the entire HUD — brackets, avatars, connector lines, translucent panels and text — onto the full-resolution frame.

NumPy

Handles the encoding arrays and the distance computation between the live face and every entry in the cached model.

pandas

Stores the face database and the optional per-person details, such as birthday and social handles, in simple tables.

Pillow

Crops and resizes the avatar images generated from the known-people photographs.

Instaloader

Powers the optional scraper that collects profile pictures from an Instagram follower list to seed the known-people database.
