Mask Detector

Real time mask detector. Identify and analysis all faces looking for a covid mask.

Python TensorFlow Keras OpenCV
~1,400images in the bundled training set
3input modes: webcam, video, photo
2-stagedetect then classify
Livemultiple faces at once

Overview

Mask Detector is a real-time computer-vision system, built during the COVID-19 period, that locates every face in a video stream and classifies each one as wearing a mask or not. It runs on a live webcam, on a recorded video file or on a single still image.

It is a two-stage pipeline, which is what makes it robust on crowded frames: a face detector finds every face in the picture, then a separate neural network classifies each face crop on its own, so several people are handled independently in the same shot.

Each face is drawn with a bounding box and a label whose colour reflects the prediction, giving an at-a-glance read on a busy scene.

What it does

Detection

  • Face detector with a confidence threshold that keeps false positives away from the classifier
  • Works on webcam, video files and still images with the same code
  • Colour-coded annotations

Classifier

  • Transfer learning from a pre-trained image network, so a small dataset is enough
  • Live data augmentation: rotation, zoom, shift, shear and flip
  • Balanced dataset of masked and unmasked faces included

Training

  • Single reproducible training run with train and test split
  • Models saved with a timestamp so none is overwritten
  • Per-class precision, recall and F1 report and training telemetry

How it is built

The face detector is a pre-trained SSD network run through OpenCV, and the classifier is a MobileNetV2 model fine-tuned with TensorFlow and Keras with a custom classification head. The whole project is plain Python.

Tech stack

Python

Three focused scripts — one to train the model, one for webcam and video inference, one for single images — sharing the same preprocessing.

TensorFlow / Keras

Builds, trains and runs the classifier: the MobileNetV2 backbone, the custom head, the Adam optimiser with decay, the augmentation generator and the saved .h5 artefacts.

MobileNetV2

ImageNet-pretrained backbone used as a frozen feature extractor — light enough for real-time inference on CPU while giving the small dataset a strong starting representation.

OpenCV (DNN module)

Runs the Caffe ResNet-10 SSD face detector via cv2.dnn.readNet and blobFromImage, captures the video stream and draws the boxes and labels.

scikit-learn

Provides the label binariser, the stratified train/test split and the final classification_report with per-class precision, recall and F1.

imutils

Supplies the dataset path walker and the VideoStream helper used by the inference scripts.

NumPy

Handles the image tensors, the batching of face crops and the array manipulation between the two inference stages.
