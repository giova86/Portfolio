Mask Detector

Real time mask detector. Identify and analysis all faces looking for a covid mask.

Python TensorFlow Keras OpenCV

Overview

Mask Detector is a real-time computer-vision system, built during the COVID-19 period, that locates every face in a video stream and classifies each one as wearing a mask or not. It runs on a live webcam, on a recorded video file, or on a single still image, and annotates each detected face with a coloured bounding box and the predicted label.

It is a two-stage pipeline, which is what makes it robust on crowded frames. The first stage is face detection: each frame is turned into a 300×300 blob and passed through an OpenCV DNN Caffe model — the ResNet-10 SSD face detector shipped as res10_300x300_ssd_iter_140000.caffemodel — and every box above a 0.5 confidence threshold is kept. The second stage is classification: each detected face is cropped, converted to RGB, resized to 224×224, preprocessed and pushed through a custom Keras model that returns a mask / no-mask probability. Splitting the two means the classifier never has to learn to localise faces, and the detector never has to know anything about masks.

The classifier itself is a transfer-learning model trained by training.py on a balanced local dataset of roughly 1 400 images (≈690 with a mask, ≈686 without). MobileNetV2 pre-trained on ImageNet is used as a frozen feature extractor, with a custom head on top: average pooling (7×7), flatten, a 128-unit ReLU dense layer, 0.5 dropout and a 2-way softmax. The base layers are frozen so only the head trains, which is what allows a usable model to come out of a dataset this small. Training runs for 30 epochs with Adam at a 1e-4 learning rate with decay, batch size 32, a stratified 70/30 split, live image augmentation through ImageDataGenerator, TensorBoard logging, and a scikit-learn classification report at the end. Trained models are saved as timestamped .h5 files, and one pre-trained model ships with the repository so the detector can be run without retraining.

Key features

  • Two-stage detect-then-classify pipeline — an SSD face detector finds every face in the frame and a separate CNN classifies each crop, so multiple people are handled independently in the same shot.
  • Three input modes — live webcam, a local video file passed with -i, or a single still image, all sharing the same inference code.
  • Transfer learning on MobileNetV2 — ImageNet weights are frozen and only a custom classification head (AvgPool → Flatten → Dense 128 ReLU → Dropout 0.5 → Softmax 2) is trained, making a ~1 400-image dataset sufficient.
  • Confidence-thresholded detection — face boxes below 0.5 detector confidence are discarded before classification, keeping false positives out of the classifier.
  • Colour-coded annotation — each face is drawn with its bounding box and label in a colour that reflects the prediction, giving an at-a-glance read on a crowded frame.
  • Reproducible training script — training.py handles loading, 224×224 preprocessing, label binarisation, the stratified 70/30 split, augmentation, 30 epochs of Adam with learning-rate decay and the final evaluation in one run.
  • Live data augmentation — ImageDataGenerator applies rotation, zoom, shift, shear and flip on the fly, expanding the effective size of a small dataset.
  • Balanced bundled dataset — ~690 masked and ~686 unmasked training images are included, so the model can be retrained from scratch out of the box.
  • Timestamped model artefacts — each training run writes its own YYYY-MM-DD_HH:MM:SS.h5, so models are never silently overwritten and runs stay comparable.
  • Training telemetry — a TensorBoard callback records the run and scikit-learn prints a per-class precision/recall/F1 report on the held-out split.

Tech stack

Python

Three focused entry points — training.py to build the model, test_video.py for webcam and video inference, test_picture.py for single images — sharing the same preprocessing conventions.

TensorFlow / Keras

Builds, trains and runs the classifier: the MobileNetV2 backbone, the custom head, the Adam optimiser with decay, the augmentation generator and the saved .h5 artefacts.

MobileNetV2

ImageNet-pretrained backbone used as a frozen feature extractor — light enough for real-time inference on CPU while giving the small dataset a strong starting representation.

OpenCV (DNN module)

Runs the Caffe ResNet-10 SSD face detector via cv2.dnn.readNet and blobFromImage, captures the video stream and draws the boxes and labels.

scikit-learn

Provides the label binariser, the stratified train/test split and the final classification_report with per-class precision, recall and F1.

imutils

Supplies the dataset path walker and the VideoStream helper used by the inference scripts.

NumPy

Handles the image tensors, the batching of face crops and the array manipulation between the two inference stages.
