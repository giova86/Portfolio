MacDown Lite - Desktop Application

A native macOS Markdown editor with live preview: syntax-highlighted source on the left, GitHub-style rendering on the right, a formatting toolbar, LaTeX formulas and HTML/PDF export.

Swift SwiftUI Markdown Javascript

Overview

MacDown Lite is a native Markdown editor for macOS built around one idea: you write raw Markdown on the left and see the formatted result on the right, instantly, with no button to press. It is a small personal project written in Swift with SwiftUI and AppKit, works fully offline and ships as a universal app (Apple Silicon and Intel) in a DMG of less than 1 MB.

The editor is a plain NSTextView with regex-based syntax highlighting and a formatting bar whose buttons act on the selection or the current line and toggle the formatting off when pressed again. The preview is a local HTML page inside a WKWebView: marked converts the text, DOMPurify sanitises any embedded HTML, highlight.js colours code blocks and KaTeX renders LaTeX formulas — all bundled with the app, so nothing is loaded from the network.

Local images are served through a custom mdfile:// URL scheme handled by the app, which lets macOS grant folder access properly. The app is document-based (new, open, save, recent files, automatic versions), the two panes can be resized with a drag handle, and a script assembles, ad-hoc signs and verifies the DMG without needing an Xcode project.

Key features

  • Live preview — the preview updates on every keystroke, with GitHub Flavored Markdown: tables, task lists, strikethrough and fenced code blocks highlighted per language.
  • Syntax-highlighted editor — monospaced raw text with colours for headings, bold, italic, links, code, quotes and lists; smart quotes and auto-substitutions are disabled so the Markdown is never altered.
  • Formatting toolbar — headings, bold (⌘B), italic (⌘I), strikethrough, inline code, bullet, numbered and task lists, quotes, indent/outdent, links (⌘K), images, tables, code blocks and horizontal rules; each button toggles.
  • Text alignment — left, centre and right alignment implemented by wrapping the selected lines in <div align> while keeping the content as Markdown.
  • LaTeX formulas — inline $…$ and block $$…$$ maths rendered with KaTeX, plus a menu of snippets (fraction, root, sub/superscript, sum, integral).
  • Independent themes — editor and preview each have an Automatic, Light or Dark setting, remembered between launches.
  • Synchronised scrolling — the preview follows the editor as you scroll.
  • Images — insert from a file (relative path when possible) or a URL; local images load through the app and a missing one shows a warning with its path.
  • Export — save the preview as a single self-contained HTML file or as a paginated PDF.
  • Flexible layout — editor only (⌘1), editor and preview (⌘2) or preview only (⌘3), with a draggable divider that resets to 50/50 on double click.
  • Safe and offline — embedded HTML is sanitised with DOMPurify, links open in the default browser, and all libraries are bundled.

Tech stack

Swift

The whole application: document model, window layout, text formatting logic and the export code, packaged as a Swift Package with no Xcode project.

SwiftUI

Window, toolbar, formatting bar, theme pickers and the resizable split view, on top of a document-based DocumentGroup app.

Markdown

The native editor is an NSTextView with regex highlighting; text commands toggle GitHub Flavored Markdown syntax on the selection.

Javascript

marked, DOMPurify, highlight.js and KaTeX run inside a WKWebView to render, sanitise and colour the preview offline.
