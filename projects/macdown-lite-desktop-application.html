MacDown Lite - Desktop Application

A native macOS Markdown editor with live preview: syntax-highlighted source on the left, GitHub-style rendering on the right, a formatting toolbar, LaTeX formulas and HTML/PDF export.

Overview

MacDown Lite is a native Markdown editor for macOS built around one idea: you write raw Markdown on the left and see the formatted result on the right, instantly, with no button to press.

It is a small personal project written in Swift with SwiftUI and AppKit. It works fully offline and ships as a universal app in a DMG of less than 1 MB.

The editor colours headings, emphasis, links, code, quotes and lists, and a formatting bar toggles styles on the selection. The preview renders GitHub-style Markdown, code highlighting and LaTeX formulas.

Write left, read right

The two panes stay in sync as you type and as you scroll, and a draggable divider lets you give more room to either side. Switch between editor only, editor and preview, or preview only whenever you want to focus.

Editor and preview each have an automatic, light or dark appearance, remembered between launches.

What it does

Editor

  • Syntax-coloured raw text that is never altered by smart quotes or auto-substitutions
  • Formatting bar for headings, bold, italic, lists, tasks, quotes, links, images, tables and code blocks — each button toggles
  • Left, centre and right alignment

Preview

  • GitHub Flavored Markdown with tables, task lists and strikethrough
  • Fenced code blocks highlighted per language
  • LaTeX formulas, inline and block, with a menu of common snippets

Documents and images

  • Document-based app with recent files and automatic versions
  • Insert images from a file or a URL; local images load correctly and a missing one shows a warning

Export and safety

  • Export the preview as a self-contained HTML file or a paginated PDF
  • Embedded HTML is sanitised and links open in the default browser

How it is built

The editor is a native text view with pattern-based highlighting. The preview is a local web page inside a web view that converts the Markdown, sanitises any embedded HTML, colours code and renders formulas, with every library bundled in the app so nothing is downloaded.

Local images are served through a custom URL scheme handled by the app, which lets macOS grant folder access properly. The DMG is assembled, signed and verified by a script, with no Xcode project needed.

Tech stack

Swift

The whole application: document model, window layout, text formatting logic and the export code, packaged as a Swift Package with no Xcode project.

SwiftUI

Window, toolbar, formatting bar, theme pickers and the resizable split view, on top of a document-based DocumentGroup app.

Markdown

The native editor is an NSTextView with regex highlighting; text commands toggle GitHub Flavored Markdown syntax on the selection.

Javascript

marked, DOMPurify, highlight.js and KaTeX run inside a WKWebView to render, sanitise and colour the preview offline.
