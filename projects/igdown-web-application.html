Overview

IGDown is a self-hosted web application for downloading Instagram Reels as video or audio. It runs entirely on your own machine — no ads, no upload limits, no third-party service in the middle.

Paste a link and the app starts a background job right away, showing real-time percentage, transfer speed and time remaining. Reels can be saved as MP4, or converted to MP3 when only the sound is needed.

Links that are not valid Instagram addresses are rejected immediately with an inline message next to the field, and finished files are removed automatically after a few minutes so a long-running instance never fills the disk.

What it does

Downloading

  • Reels as video or extracted audio
  • Several downloads in parallel without blocking the interface
  • Real-time progress, speed and ETA

Convenience

  • Clear inline errors for malformed links
  • Dark and light themes remembered between sessions
  • Automatic cleanup of finished files

Private

  • Runs fully locally with no account or tracking
  • Nothing leaves the machine except the request to Instagram itself

How it is built

A download is not a blocking request: the back end registers a job and returns immediately, hands the work to a small pool of workers and streams progress to the browser as it happens. The FastAPI back end is cleanly separated into schemas, routes and a download service built on yt-dlp, so the engine can be swapped without touching the API, and it is covered by an automated test suite. The React and TypeScript front end drives the whole flow through a single progress state machine.

Tech stack

Python

Powers the backend: the job registry, the thread-pool execution model, the progress hook that feeds the SSE stream and the scheduled cleanup of finished files.

FastAPI

Exposes the three endpoints (create job, stream progress, fetch file), validates requests through Pydantic models, and manages startup/shutdown through the lifespan hook.

yt-dlp

The download engine; its progress callback produces the percentage, speed and ETA the interface displays.

Server-Sent Events

A one-way stream from server to browser carrying job status updates — lighter than WebSockets for this shape of problem, and it closes itself when the job reaches a terminal state.

React + TypeScript

Builds the interface around a useDownload hook implemented as an SSE state machine, with typed components for the download card, progress bar, toasts and theme toggle.

Vite

Provides the development server and build pipeline for the front end.

ffmpeg

Extracts and encodes the audio track when a reel is requested as MP3.

pytest

Covers the downloader service, the request/response models and the API routes.
