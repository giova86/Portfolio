Overview

JSON Formatter is a small, focused utility for pretty-printing and validating JSON: paste raw JSON on the left, get a formatted, indented version on the right, with any syntax error pointed out at the exact line and column where it occurs.

It was built to be the kind of tool you keep open in a tab: fast, clean and with nothing in the way.

Paste, read, copy

The output can be copied to the clipboard or downloaded straight from the panel. Non-ASCII characters are preserved as they are instead of being escaped, and the two-column view stacks into a single column on mobile.

What it does

Format

  • Re-indents any valid JSON with a configurable width
  • Unicode-safe output

Validate

  • Invalid input is reported with the exact line and column of the problem

Comfort

  • Dark and light themes with smooth transitions, remembered between sessions
  • Responsive layout for phones
  • Copy and download from the output panel

How it is built

A React and Vite single-page app talks to a small Flask API with a single endpoint. The back end parses the text with Python's own JSON parser and returns either the formatted result or the position of the error.

Tech stack

Python

Backend language for the Flask API and the JSON parsing/formatting logic.

Flask

Exposes the single endpoint that validates and pretty-prints the submitted JSON.

React

Drives the two-panel interface — input, output, indent selector, and theme toggle.

Vite

Dev server and build tool for the React front end, with a proxy to the Flask API during development.
