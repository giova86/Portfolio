Alfabeto LIS

A machine learning model that detects the right hand, extracts the main features, and predicts the corresponding sign in Italian Sign Language based on hand shape.

Overview

Alfabeto LIS recognises letters of the Italian Sign Language (LIS) alphabet from a single webcam frame. It watches the user's right hand, classifies the static shape it is making, and reports the predicted letter together with a confidence value for every letter of the alphabet.

Because the classifier works frame by frame, only signs that hold a static shape can be recognised. The letters G, J, S and Z rely on motion in the air, so they are deliberately left out, leaving 22 letters.

The same trained model powers three experiences: a desktop application with a live camera window, a public web demo, and a browser app that streams video to a server and shows the prediction as you sign.

What it does

Recognition

  • Real-time tracking of the right hand under varying light and distance
  • Landmarks are normalised on the hand itself, so the result does not depend on how close the hand is to the camera
  • The full confidence spectrum is shown, revealing which letters are easily confused

Feedback

  • A clear "hand detected" or "searching" indicator in every interface
  • The top prediction and every letter's probability shown live

Three front ends

  • Desktop app with a live camera overlay
  • Public web demo
  • React single-page app streaming frames over a persistent connection

Reproducible

  • Guided data collection with an on-screen countdown for each letter
  • Retraining in a single step with train and test accuracy reported
  • Adjustable sample counts and confidence thresholds

How the prediction works

Each camera frame goes through the same pipeline everywhere. A hand-tracking model locates 21 three-dimensional landmarks on the right hand, the coordinates are rescaled against the hand's own bounding box and flattened into a 63-value description, and a support-vector classifier trained with scikit-learn returns the most likely letter along with the probability of all 22 classes.

In the browser app, frames travel to a FastAPI server over a single WebSocket, throttled by waiting for each reply before sending the next frame, so the connection never backs up.

Tech stack

Python

The core of the project: data collection, training, real-time prediction and the web back end are all plain Python built on the same normalisation logic.

Scikit-learn

Trains and serves the classifier: an SVC(probability=True) Support Vector Machine fit on the collected landmark dataset with train_test_split, then pickled to disk and loaded unchanged by every front end (OpenCV, Streamlit, FastAPI).

Mediapipe

Its Holistic solution is what turns a raw frame into 21 3D right-hand landmarks per frame — the single input every other layer of the pipeline (normalisation, training, inference) is built around.

OpenCV

Handles all image I/O and rendering on the desktop app: reading webcam frames, colour-space conversion for Mediapipe, and drawing the ink-and-amber viewfinder, hand-detection tag and confidence-spectrum sidebar directly onto the video feed.

FastAPI & WebSockets

The React app's backend: a single /ws WebSocket endpoint decodes each incoming base64 JPEG, runs it through Mediapipe and the SVM, and streams back a JSON payload with the hand-detection flag, the predicted letter, its confidence and the full per-letter probability map.

React

Drives the webcam capture loop and the live UI: a Camera component grabs frames onto a hidden canvas and gates the send rate on the backend's last reply, while a PredictionSidebar renders every letter as an animated confidence bar, highlighting the current top prediction.

Streamlit

Serves the trained model as a public, install-free web demo, so the classifier can be tried directly in the browser without running the Python scripts or the React/FastAPI stack locally.
