Wikimens - Mobile Application

Mobile app that allows you to guess the word the user searched on Wikipedia through secret notifications.

Overview

Wikimens is a mentalism prop disguised as an ordinary Wikipedia browser. To the spectator holding the phone it is simply the Italian Wikipedia: a full-screen page with no toolbar, no menu, no settings and no branding of its own. They search for any word they like.

Behind the scenes, the word they search for is quietly captured and delivered as a notification to the performer's own phone or smartwatch, readable straight from the lock screen.

Two details make it a usable routine rather than a demo: a configurable delay, so the performer's phone does not buzz the instant the spectator types — and a mistyped search can be corrected — and a silent design that never shows an error in front of the audience.

What it does

Capture

  • Search captured as it is typed
  • Queries also recognised from the address of the results page
  • Only words the user actively searched are sent, not links followed inside an article

Delivery

  • Notification with the word as its title
  • Delay from instant to five minutes
  • Duplicate searches within a few seconds are merged

Hidden controls

  • A multi-tap on an invisible corner area opens the settings
  • Without a topic set, the app sends nothing and behaves as a plain browser
  • Network failures are swallowed silently

How it is built

The app loads the real Italian Wikipedia in a full-screen web view and injects a small script that follows the page as it changes. Notifications travel through the public ntfy service, with no account and no Firebase project. Built with Flutter, it targets Android, iOS, macOS, Windows and Linux from a single codebase.

Tech stack

Dart

Implements the interception pipeline: SearchInterceptor's URL parsing, the article slug fallback, the duplicate-suppression window and the deferred-send timer that schedules the notification.

Flutter

Hosts the app as a single full-screen widget tree — WebView plus an invisible corner gesture detector — and provides the modal bottom sheet used for the hidden settings panel.

webview_flutter

Embeds Wikipedia with unrestricted JavaScript, exposes the onPageFinished hook used to inject the search listener, the onNavigationRequest delegate used to inspect URLs, and runJavaScriptReturningResult to read back the captured query.

Injected JavaScript

A guarded, idempotent snippet that binds an input handler to Wikipedia's search fields and re-scans the DOM through a MutationObserver, surviving the site's client-side navigation.

ntfy.sh + http

Posts the captured word as a plain-text notification with a title, swallowing every error so failures stay invisible.

shared_preferences

Stores the ntfy topic and the notification delay on-device, keeping the app stateless from the spectator's point of view while remembering the performer's configuration between sessions.
